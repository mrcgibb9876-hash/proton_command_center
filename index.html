Toggles

DLSS Super Resolution

Custom scaling ratio needs a recent Proton (dxvk-nvapi 0.9.1+). Preset list is read from the selected Proton build's own dxvk-nvapi — greyed-out presets aren't compiled into that build.

DLSS Frame Generation

Multi-frame (3x-6x) needs an RTX 50-series card. 5x/6x are new in DLSS 4.5's Dynamic Multi Frame Generation and need a recent Proton/GE build (dxvk-nvapi 0.9.2+) - if your build's older, pick 4x instead. Pair with Reflex.

Advanced preset options

Picking a render preset only tells the game which model to use — it doesn't fetch the model itself. Turn on "DLSS auto-updater (NGX)" in the toggle list above too, or the preset may not exist yet in this game's bundled DLSS DLL.

The global default is a template only — saving it never touches any game's launch options by itself. "Apply" copies it into the SR/RR/FG controls above for the game you're currently editing.

AMD FSR

FSR's upscaling quality mode is normally an in-game setting — unlike DLSS, there's no universal Proton env var to force it from outside the game. The FSR4 upgrade toggle above (in the toggle list) covers replacing the game's bundled FSR DLLs with FSR4 on RDNA3/RDNA4 cards.

This section is new and community-sourced — not verified against real AMD hardware by this app's author. If something here is wrong, please open an issue.
